# 🏥 Sistema de Informática Médica

Sistema web integral para el curso de Informática Médica, desarrollado con Flask y PostgreSQL, diseñado con la estética de iOS en colores blanco y verde.

## 🚀 Características

### Para Estudiantes
- 📝 **Registro autónomo** con validación segura
- 📤 **Subida de tareas** con historial completo
- 📥 **Descarga de materiales** del curso
- 💬 **Sistema de mensajes** con el profesor
- 📊 **Dashboard personalizado** con estadísticas

### Para Profesores
- 👥 **Gestión de estudiantes** y sus trabajos
- 📋 **Calificación de tareas** con feedback
- 📚 **Subida de materiales** del curso
- 📢 **Sistema de mensajes** individuales y anuncios
- 📈 **Dashboard administrativo** con métricas

## 🛠️ Tecnologías Utilizadas

- **Backend**: Flask 2.3.3, SQLAlchemy, PostgreSQL
- **Frontend**: Bootstrap 5.3, CSS personalizado (estilo iOS)
- **Autenticación**: Flask-Login con validaciones
- **Seguridad**: Protección CSRF, validación de archivos
- **Despliegue**: Render.com

## 📋 Requisitos Previos

- Python 3.8 o superior
- PostgreSQL 12 o superior
- Git
